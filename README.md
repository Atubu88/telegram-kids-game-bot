# telegram-kids-game-bot

MVP Telegram-бот для родителя: игровая система поведения для 2 детей.

## Текущая логика

- Одна валюта: `⭐️`
- Каждую неделю в **понедельник** каждому игроку начисляется `+30 ⭐️`
- Ничего не сгорает
- Магазин тратится из этих же `⭐️`
- `🏆` общий прогресс остаётся отдельно и растёт только от положительных начислений
- История недель сохраняется как снимок состояния на конец прошлой недели

## Стек

- Cloudflare Workers
- Telegram Bot API
- Cloudflare D1
- Wrangler

## Что уже есть в MVP

- 2 игрока по умолчанию: `👦 Игрок 1` и `👦 Игрок 2`
- Единый баланс `⭐️`
- Долгосрочный прогресс `🏆`, который:
  - растёт только от положительных начислений
  - не уменьшается от штрафов
  - не уменьшается от покупок
- Уровни по текущему балансу
- История начислений/списаний/покупок
- Индивидуальное открытие/закрытие магазина для каждого игрока
- Общий магазин с товарами
- Еженедельный бонус `+30 ⭐️` по понедельникам
- Сохранение недельных итогов в историю

## Логика штрафа

После `➖ Снять` бот спрашивает:
- закрыть магазин тоже или нет

Это позволяет:
- за мелкий проступок просто снять очки
- за серьёзный проступок снять очки и сразу закрыть магазин

## Структура

- `src/index.js` — Worker + Telegram webhook логика
- `schema.sql` — D1 схема и seed-данные
- `wrangler.jsonc` — конфиг Wrangler

## Переменные окружения

Нужно задать секрет:

```bash
wrangler secret put TELEGRAM_BOT_TOKEN
```

## Создание D1

```bash
wrangler d1 create kids_game_bot
```

После этого вставь `database_id` в `wrangler.jsonc`.

## Применение схемы

Локально:

```bash
wrangler d1 execute kids_game_bot --local --file=./schema.sql
```

Удалённо:

```bash
wrangler d1 execute kids_game_bot --remote --file=./schema.sql
```
